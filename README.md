# Цена и прибыль · ANODHAS AI

Открытый офлайн-калькулятор для Mac. Помогает увидеть, что остаётся с одной продажи и за месяц после введённых расходов, и сравнить варианты цены, затрат и объёма продаж.

Нативное приложение на SwiftUI, AppKit и Foundation. Без сторонних библиотек, аккаунта, сервера, подключения к модели и сетевых запросов.

## Возможности

- Пять полей с точным вводом и ползунками: цена, переменные расходы на единицу, продажи за месяц, постоянные расходы и комиссия с выручки.
- Результат месяца, вклад с продажи, его маржинальность и количество продаж для безубыточности.
- Расшифровка выручки и расходов, сравнение с исходным примером.
- Три примера, переключаемые кнопками или Command-1, Command-2 и Command-3.
- Автоматическое сохранение последнего корректного расчёта на этом Mac. Неверные данные не перезаписывают его.
- App Sandbox без сетевых разрешений. Закрытие последнего окна завершает приложение; автозапуска и фоновой службы нет.

## Пример

Условные данные: 100 продаж в месяц, комиссия 3%, постоянные расходы 20 000 ₽. Без налогов и других неуказанных статей.

| Сценарий | Цена | Переменные расходы на единицу | Вклад с продажи | Результат месяца |
| --- | ---: | ---: | ---: | ---: |
| Исходный | 1 000 ₽ | 700 ₽ | 270 ₽ | +7 000 ₽ |
| Расходы выросли | 1 000 ₽ | 840 ₽ | 130 ₽ | −7 000 ₽ |
| Повысили цену | 1 200 ₽ | 840 ₽ | 324 ₽ | +12 400 ₽ |

Вклад с продажи = цена − переменные расходы − комиссия. Результат месяца = вклад × количество − постоянные расходы. Безубыточность округляется вверх до целой продажи; при неположительном вкладе покрыть положительные постоянные расходы невозможно.

Объём продаж задаёт пользователь. Пример не предсказывает, сколько людей купит товар после изменения цены.

## Сборка

Нужен Mac с Apple Command Line Tools и совместимыми Swift/macOS SDK. Интернет и менеджер пакетов не нужны.

```sh
git clone https://github.com/zakras030997-byte/anodhas-price-profit.git
cd anodhas-price-profit
bash Scripts/build.sh
bash Scripts/package.sh
```

Результат — `releases/1.0.0/Цена и прибыль.app` и `releases/1.0.0/Price-Profit-1.0.0-universal.dmg`. Сборка запускает расчётные тесты, создаёт обе архитектуры, собственную иконку и локальную подпись; упаковка проверяет контрольную сумму DMG. GitHub Actions повторяет сборку на macOS и сохраняет тестовый DMG как артефакт.

Если установленный компилятор не совместим с выбранным по умолчанию SDK, передайте путь к совместимому SDK только для этой сборки:

```sh
PRICE_PROFIT_SDK=/path/to/compatible/MacOSX.sdk bash Scripts/build.sh
```

Пример локальной сборки автора: Swift 6.3.3 и явно выбранный SDK 26.5. Глобальные настройки Xcode для этого не менялись.

## Проверки

- 38 локальных проверок: примеры, сверка результата с выручкой и затратами, граничные значения, дробные суммы, ввод с запятой, неверный ввод и формат сохранения.
- Установка из DMG и реальная проверка окна на Apple Silicon: кнопки сценариев, изменение количества, ползунок, ошибка пустого поля и восстановление после закрытия и повторного запуска.
- Исполнение на других Mac и первый запуск скачанного подписанного приложения пока не подтверждены.

Отчёты формируются в `Verification/`, но локальные журналы и пути не включаются в Git.

## Точность и ограничения

Расчёт — Foundation Decimal; округление до копеек выполняется при показе. Денежные поля: 0–10 000 000 ₽, количество: 0–1 000 000, комиссия: 0–100%. Ввод с точкой или запятой, до двух дробных знаков; количество — целое. Пустое или неверное поле блокирует показ результата.

Модель одной позиции в рублях, без НДС, других налогов, процентов, амортизации, возвратов, фиксированных комиссий за заказ и прогноза спроса. «Результат месяца» учитывает только введённые статьи; это не бухгалтерская чистая прибыль. Не включайте одну статью одновременно в переменные и постоянные расходы.

## Подписанный выпуск

При наличии собственного Developer ID Application:

```sh
SIGN_IDENTITY='Developer ID Application: YOUR NAME (TEAMID)' bash Scripts/build.sh
bash Scripts/package.sh
```

Notarization не запускается автоматически. Перед распространением нужно пройти [штатную процедуру Apple](https://developer.apple.com/developer-id/), прикрепить билет и проверить установку скачанного DMG на другом Mac. Сертификаты, ключи, пароли и авторизация Apple в репозиторий не входят.
